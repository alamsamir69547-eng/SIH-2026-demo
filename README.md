# SIH-2026-demo 
Make a main folder named HeritageIndia.Inside it, make the main file app.py - this is the brain of project.In app.py, we create a dictionary to store culture of all states like Assam, Rajasthan.Each state has festival, food, clothing, craft and famous places.We make a home route that opens the website page.We make an API /api/culture that sends all cultural data to frontend.We make /api/search that filters states when user types Bihu or Pongal.We make /api/places that gives latitude-longitude for the map.We make /api/upload to save user uploaded image.We make /api/analyze to check the image name and guess the culture.Then make a folder named templates for HTML.Inside templates, make index.html with 4 parts - hero, explore, map, AI.Hero is for welcome message, explore is for state cards.Map section shows India map with cultural markers.AI section has upload button to test cultural objects.Then make a folder named static for design and logic.Inside static, make style.css to design cards, navbar and buttons.Inside static, make script.js to fetch data from Flask and show it.script.js also handles search, map markers, and image preview.Create one empty folder named uploads to store images, then run the project.
